# Upstream versions

This workspace vendors source snapshots from the following upstream repositories:

- `src/rtabmap`: <https://github.com/introlab/rtabmap.git>, commit `e321999b`
- `src/rtabmap_ros`: <https://github.com/introlab/rtabmap_ros.git>, commit `2eef2b32`

The upstream `.git` directories were intentionally removed so this workspace can
be maintained as one repository. Original license and copyright files remain in
their respective source directories.
